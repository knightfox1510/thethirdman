# Third Man control room

Static dashboard for The Third Man: tracker, formats (rules, structure, sample frames), playbook, daily ideas, library, data and rules.

- Deploy: Vercel → Add New Project → import `knightfox1510/thethirdman` → no framework, no build. `vercel.json` serves this folder. Every push redeploys.
- Data lives in `site/data/`:
  - `formats.json`: formats, channel-wide rules, playbook. Edited by hand.
  - `schedule.json`: snapshot of the schedule sheet (the sheet stays the place to edit).
  - `fixtures.json`, `ideas/<date>.json`, `ideas/index.json`: written by the daily ideas task.
  - `library.json`, `stills.json`, `replay_sample.json`: generated by `python3 site_build.py`.
- Local preview: `cd site && python3 -m http.server` then open http://localhost:8000.
